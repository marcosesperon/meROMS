# ES-DE launch configuration

`es_systems.xml` and `es_find_rules.xml` for each OS, copied unchanged from ES-DE
(https://gitlab.com/es-de/emulationstation-de, `resources/systems/<os>/`, master branch,
downloaded on 2026-11-11). meROMS uses them to launch games the same way ES-DE does.

ES-DE is released under the MIT license; its copyright notice is in `LICENSE` next to this file.
To update them, download the same files again and replace these.
